# 逐字品質複檢（2026-10-26）

範圍：40 個詞語字（`assets/chars`）+ 9 個結構示範（`assets/examples`），共 49 張 800×800 圖。

## 方法

1. **逐字目視**：4 張 10 字對照表（字高約 410 px）先掃一遍，再對 12 個可疑交界做 5–10× 放大確認。
2. **量化**（不看 `part_of` 當裁判）：
   - `_src/qc.py` — 畫布層：未上色、色數、缺色部件、內洞細縫。
   - `_src/qc_stroke.py` — 筆畫層：一筆之內出現「沒有其他筆畫經過」的異色塊。
   - 逐圖檢查：顏色是否只用部件色、alpha 是否只有 0/255（P6）、內洞面積分佈。
3. **修法**：`_src/patch_colour.py`，只把錯切區塊的像素改回正確部件色，不改幾何、不動其他像素；規則以墨跡外框歸一化座標表示，可重複執行。

## 全站體檢（49 張）

| 檢查 | 結果 |
|---|---|
| 顏色 | 每張只用 1–4 個部件色（單部件字 1 色） |
| 非部件色像素 | **0**（全部是 `radical` / `part` / `part2` / `part3` 四色的實色） |
| alpha | 只有 0 / 255，**無半透明邊**（P6 成立，不會再出現雙線性接縫） |
| 內部細縫（≤60 px 內洞） | 合計 **3 px**（聲 2、球 1） |
| 未上色墨跡 | **0** |
| 孤兒圖（不被頁面引用） | 5 張已刪（國、思、意、湖、病 在 `chars/` 的重複舊圖，抗鋸齒版本，容易誤判） |

|---|---|---|
| 國 | 囗 的上橫中段被判給「或」，上橫變成紅–藍–紅 | 5,425 |
| 意 | 日 的右豎下半與底橫右端被判給「心」，日 的右邊整條變紅 | 6,120 |
| 默 | 黑 的第三、四點（灬）被判給「犬」，四點中兩點變藍 | 8,318 |
| 烈 | 刂 的豎鉤末端被判給「灬」，鉤變成紅色 | 3,246 |

修正後逐字放大複核：上列 6 字的部件色塊已完整，其餘 43 張像素未改動。

## 重跑

```bash
python3 _src/qc.py                 # 畫布層體檢（49 張）
python3 _src/qc.py --sheet _preview/qc   # 另出 5 張 10 字對照圖
python3 _src/qc_stroke.py          # 筆畫層殘留色
python3 _src/patch_colour.py --dry # 預覽修色規則（已是目標色者為 0 px）
python3 _src/patch_colour.py       # 套用並重建 index.html
```

`patch_colour.py` 的規則是冪等的：修好之後再跑一次，每條規則都是 0 px。
